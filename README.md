# HBG Makeup — Primera versión
Web estática responsive, sin dependencias de compilación.

## Vista local
Abre `index.html` en el navegador, o inicia un servidor local con `python3 -m http.server 8000` desde esta carpeta y visita `http://localhost:8000`.

## Antes de publicar
1. Configura `whatsapp`, `instagram`, `tiktok` y, si procede, `dossier` en `script.js`.
2. Sustituye los bloques de fotografías por imágenes propias optimizadas y con texto alternativo descriptivo.
3. Revisa todos los textos y servicios, y enlaza el dosier final.
4. Completa la política de privacidad y el aviso legal con datos reales y revisa obligaciones legales aplicables.
5. Prueba enlaces, accesibilidad y visualización en móvil.

El botón de WhatsApp solo se activa al configurar el número; nunca se envían mensajes automáticamente.
